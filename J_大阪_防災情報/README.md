# 大阪 台風情報（3面サイネージ・本番）

全体回廊 **640×192**（左128 / 正面384 / 右128）。

| ファイル | 役割 |
|----------|------|
| `index.html` | 本番画面 |
| `serve.js` | ローカル配信（port 8766） |
| `start.bat` | 起動 |

## 起動

```bat
start.bat
```

サイネージ実寸: `http://127.0.0.1:8766/?native640=1`

気象庁 `bosai/typhoon` を5分ごとに再取得。出典表示あり。独自予報はなし。
