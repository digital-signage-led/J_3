# 大阪 台風情報（自販機サイネージ 640×192）

雨雲（アメダス）と同じ起動方式です。

## 起動

- **サイネージ:** `start.bat` → 左上 `(0,0)` に 640×192（DPI倍率1倍）
- **PC確認:** `open-preview.bat`

LED取り込みは左上 640×192 をキャプチャ。  
表示が真っ黒／何も見えないときは、一度ウィンドウを閉じて `start.bat` を再実行してください。

## 面割り

| 面 | 幅 | 内容 |
|----|----|------|
| 左 | 128 | 号数 or 気圧・種別・時計 |
| 正面 | 384 | 台風進路図 |
| 右 | 128 | 大阪への影響 |

## ファイル

| ファイル | 役割 |
|----------|------|
| `index.html` | 本番画面 |
| `vendor/leaflet/` | 地図ライブラリ（CDN非依存） |
| `serve.js` / `start.bat` | 配信・サイネージ起動 |

気象庁 `bosai/typhoon` を5分ごとに再取得。出典表示あり。
