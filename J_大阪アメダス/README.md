# 大阪 雨雲レーダー（自販機サイネージ 640×192）

## 起動

- **サイネージ:** `start.bat` → 左上 `(0,0)` に 640×192  
- **PC確認:** `open-preview.bat`

LED取り込みは左上 640×192 をキャプチャ。  
Windowsの拡大表示（125%/150%）が入っていても、専用プロファイルで倍率1倍に固定します。表示がずれるときは一度ウィンドウを閉じて `start.bat` を再実行してください。

## 面割り

| 面 | X | 幅 | 高さ | 役割 |
|----|---|----|------|------|
| 左面 | 0 | 128 | 192 | 雨の目安 |
| 正面 | 128 | 384 | 192 | 雨雲の動き |
| 右面 | 512 | 128 | 192 | 雨の強さ・出典 |

## 出典

気象庁 / 地理院（画面内に表示）
