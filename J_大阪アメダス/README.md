# 大阪 雨雲レーダー（自販機サイネージ 640×192）

現場向け雨雲レーダータイルです。自販機／LED 筐体の **640×192・3面** に合わせています。

## データ取得（特定PCに依存しません）

雨雲・アメダスは **気象庁サイトへブラウザから直接取得** します。  
表示用PCのプロキシ常時起動は不要です。サイネージがインターネットに繋がっていれば動作します。

## 起動（任意）

ローカル確認用に簡易サーバを用意しています。

1. `start.bat` を実行
2. 確認用: `http://127.0.0.1:8765/?preview=1`
3. LED本番: `http://127.0.0.1:8765/?signage=1`  
   またはサイネージに `index.html` を置き `?signage=1` で開く

## 面割り（原点 x=0, y=0）

| 面 | X | 幅 | 高さ | 役割 |
|----|---|----|------|------|
| 左面 | 0 | 128 | 192 | 雨の目安 |
| 正面 | 128 | 384 | 192 | 雨雲の動き |
| 右面 | 512 | 128 | 192 | 雨の強さ・出典 |

## 本番に必要なファイル

| ファイル | 内容 |
|----------|------|
| `index.html` | 雨雲レーダー本体 |
| `vendor/leaflet/` | 地図ライブラリ |
| `serve.js` / `start.bat` | 任意（ローカル確認用） |

## 出典・利用上の注意

画面上に出典（気象庁 / 地理院）と目安表示である旨を表示しています。

- [気象庁ホームページについて](https://www.jma.go.jp/jma/kishou/info/coment.html)
- [国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)

商用で予報として対外提供する場合は、気象業務法上の許可の要否を別途確認してください。
